# Backend

메타넷 5조 백엔드 레포입니다.

---

## 📝 프로젝트 소개
- 사용자가 영화 목록을 확인하고 예매 및 결제하여 티켓을 구매할 수 있는 서비스입니다. 
- 영화 예매, 결제, 티켓 조회 등의 기능을 제공합니다.
---

## 📦 기술 스택
  - **Backend:** Spring Boot, MyBatis, JWT, Oracle, Redis
  - **Infra:** AWS EC2, Docker
  - **CI/CD:** GitHub Actions
